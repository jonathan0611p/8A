
# Purpose C# Project 
## 1. Project Overview

**Project Name:** Lov3rs Plaza

**Language:** C#

**Purpose:** Build and maintain a C# application while keeping the code organized and documenting the team's progress.

## 2. Project Structure

```text
CSharpApplication/
├── MainWIndow.cs
├── Context.md
├── README.md
├── Assets/
├── Evidence/
```

- `MainWIndow.xaml.cs` — Main application entry point.
- `Assets` — The help we receive, IA.
- `Evidence` — Our images.
- `README.md` — Project description and setup instructions.
- `Context.md` — Project rules and team activity log.

## 3. Coding Rules

- Write simple, readable C# code.
- Use descriptive names for variables, classes, and methods.
- Keep code organized.
- Test changes before submitting them.
- Do not overwrite another team member's work without discussing it.
- Never upload passwords or private keys.
- Update documentation when important changes are made.
